## 8. 对不同模型格式的理解与实验结论
`.pt` 是PyTorch原生模型格式，和PyTorch框架深度绑定，适合模型训练、迭代调试，在PyTorch原生环境中CPU推理速度表现不错，但跨平台、跨框架部署存在限制。
ONNX是开放式通用模型格式，它将网络结构与权重独立封装为标准化计算图，脱离特定训练框架，能够对接TensorRT、OpenVINO、ONNXRuntime等多种推理引擎，是工业部署常用格式。
本次实验中，转换得到的ONNX模型检测精度和原pt模型基本一致，说明本次模型转换是成功的。但在普通CPU+ONNXRuntime环境下，它的推理速度反而慢于pt，文件体积也更大，原因是没有做算子融合、量化等图优化。
结论：ONNX的优势不在于直接在普通CPU上跑，而在于方便移植到不同硬件、不同推理引擎；经过图优化、量化、专用后端加速之后，ONNX才能体现出部署上的速度优势。
