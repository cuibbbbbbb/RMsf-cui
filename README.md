# YOLO装甲板推理项目

## 1. 项目完成的功能
基于YOLO模型完成装甲板视频推理，输出包含检测框、类别、置信度及4个关键点的结果视频。

## 2. 环境说明
- Python 版本：Python 3.13
- 主要依赖：ultralytics, opencv-python
- 运行设备：CPU

## 3. 模型权重的准备方式与放置位置
需自行获取 `best.pt` 模型文件，将其放置在项目根目录下（与 `infer.py` 同级）。

## 4. 依赖安装步骤、实际运行命令和结果保存位置
- 安装依赖：`pip install -r requirements.txt`
- 运行命令：`python infer.py`
- 结果保存位置：推理结果视频自动保存在 `runs/pose/predict/` 文件夹下。

## 5. 视频拍摄地点、时长及场景说明
- 拍摄地点：水建学院D414实验室
- 拍摄时长：约18秒
- 场景说明：横屏拍摄，包含清晰可见的装甲板，适当改变了距离或角度。
