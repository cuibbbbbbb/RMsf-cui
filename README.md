# YOLO模型导出与推理对比实验
## 一、项目简介
本项目实现YOLO `.pt` 权重文件向ONNX格式模型的转换，并在相同环境下分别使用原始pt模型、
导出后的ONNX模型对同一视频进行推理，完成结果与性能对比。

## 二、运行环境
- Python版本：3.13
- 主要依赖：ultralytics、torch、opencv-python
- 运行设备：CPU
- 推理统一参数：conf=0.25，iou=0.45，输入尺寸640×640
## 三 使用方法
豆老师
## 四、推理结果与分析
使用同一段测试视频作为输入，在完全一致的软硬件环境下对照测试。两个模型在视频各帧中均可稳定检出1个目标，检测框位置、置信度基本一致，模型转换后检测精度没有明显损失。
本次CPU环境测试中，pt模型总推理耗时更短。原因是PyTorch原生后端MKL算子优化程度更高；ONNX采用ONNXRuntime CPU后端，算子优化不足。
本次导出得到的ONNX文件体积大于原始pt模型，是因为导出时没有开启图优化、量化压缩。ONNX适合部署在TensorRT、OpenVINO等专用推理后端，优化后可以发挥速度优势。
